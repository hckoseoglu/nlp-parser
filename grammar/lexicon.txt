# CMPE 561 Application Project 2 - lexicon: word forms
#
# The output we assume from the morphological analyzer: for every word form
# its Penn Treebank tag and its analysis as stem+suffix.
#
# Format:  word-form   tag   analysis   [feature=value ...]   # source of the word
#          analysis is "-" when the word has no suffix (it is its own stem)
# A word form with several possible tags has one line per tag.
#
# The features of a word form come from three places, later ones win:
#   1. its tag            (tags.txt:   NNS is plural, VBD is past, ...)
#   2. its stem           (stems.txt:  go needs a "to" phrase, music is a mass noun, ...)
#   3. this line          (only for irregular forms: am, are, was, were)
#
# Where the words come from (the comment on the first line of each word):
#   assignment       the example sentences of the assignment and our test sentences
#   SLP2 Fig. 5.x    closed-class lists in Jurafsky & Martin, Speech and Language
#                    Processing (2nd ed.), section 5.1, taken from the CELEX dictionary
#                    (Baayen et al., 1995). Kept: words in current use that fit the
#                    constructions of our grammar.
#   PTB guidelines   the determiners listed for the tag DT in Santorini (1990)
#   NGSL n           New General Service List 1.2 (Browne, Culligan & Phillips, 2013),
#                    n = frequency rank of the word. The tag, the forms and the
#                    features are ours.
#   own              added by us

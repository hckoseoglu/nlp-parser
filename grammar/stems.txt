# CMPE 561 Application Project 2 - stems: the dictionary part of the lexicon
#
# Features that belong to the word itself and hold for all its forms: which
# complements a verb takes, whether a noun can stand without a determiner, ...
# A word form finds its stem through its analysis in lexicon.txt
# (went -> go+ed -> the entry "go" below). Words without a suffix are their
# own stem. A stem may have several lines (do: auxiliary and main verb).
#
# Format:  stem   class   feature=value ...
#          class is a tag, or one of the shorthands defined here.
# A stem that needs no feature of its own (friend, the, historical) has no line.
#
# Features set here (all are explained in features.md):
#   agr, case      person/number and subject/object form of pronouns; number of determiners
#   pro            the determiner can stand alone as a noun phrase (this, some, both)
#   bare           the noun can stand without a determiner (mass nouns, time words)
#   temporal, time the noun is a time expression / when it refers to
#   frame          the complements the verb allows (none, NP, PP, NP_PP, NP_NP, ADJP, ADVP, VP)
#   prep           the preposition its PP must have
#   aux, vpform    auxiliary; the form of the verb phrase it asks for
#   adv            kind of adverb (place, deg, neg; default vp)
# The frames and the bare/temporal values were assigned by us.
